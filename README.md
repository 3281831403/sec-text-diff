审批通过的变更单在应用差异补丁时，反向应用无法还原原文，攻击者因此在审批后偷偷改掉了一行配置：只改了一个空格却显示整段重写，行号还整体偏移了一位。防篡改契约要求按行比较时行尾换行符必须先归一，空白差异按策略选择忽略或保留，新增与删除都要标注行号且行号从一起算，相等行不得出现在差异块中。变更块必须支持反向应用并还原原文，空文件与单个空行必须区分，批量比较时各对结果互不影响。不变量：差异反向应用后必须得到原文，同一输入无论比较多少次结果都必须相同。
